### Typography system

**Playfair Display**

-  Main headlines: `40pt` cover / `23pt` document H1 
-  H2: `16pt` 
-  H3: `12.5pt` 
-  Italic emphasis is heavily used 
-  Weight mostly `500`, with H3 at `600` 

**Montserrat**

-  Body: `9.6pt` 
-  Body line-height: `1.65` 
-  Small labels: `7–8pt` 
-  Uppercase labels use roughly `0.18–0.20em` letter spacing 
-  Weight mainly `400–600` 

### Visual personality

The code strongly suggests a **feminine, editorial, sophisticated personal-brand identity**:

**Luxury / Editorial**
 → Playfair Display
 → Large serif headlines
 → Italic typography
 → Generous whitespace

**Modern / Professional**
 → Montserrat
 → Uppercase micro-labels
 → Minimal borders
 → Structured grids/tables

**Energetic / Empowering**
 → `#E9202E` red
 → Coral `#E88A90`
 → Pink/blush supporting tones

**Overall aesthetic:**

> **Editorial luxury + modern feminine + bold red energy**
